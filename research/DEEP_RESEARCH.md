**Research status:** Detailed research draft — pehle product ka focus choose karein: learning tool, Git client ya repository collaboration.

## 1. Git kya hai?
Git code aur files ke changes ka history rakhta hai. Isse team dekh sakti hai ki kya badla, kisne badla aur purane version par kaise wapas jaana hai. GitHub jaisi hosting service repository ko online rakhkar collaboration mein help karti hai.

## 2. Kiske kaam aayega?
Developers, students, open-source contributors aur project teams.

## 3. Product ka focus kya ho?
Teen possible directions hain:
- **Learning tool:** Git commands ko examples ke saath sikhana.
- **Git client:** Branches, changes, commits aur conflicts ko visual tareeke se manage karna.
- **Repository platform:** Online repositories, pull requests aur team permissions dena.
Teeno ek saath banana bahut bada scope hai; pehle ek direction choose karein.

## 4. Main features
1. Repository create/clone.
2. Working changes aur diff dekhna.
3. Files stage aur commit karna.
4. Branch aur tag manage karna.
5. Pull/push/fetch.
6. Merge aur conflict resolution.
7. Commit history aur branch graph.
8. Revert/restore jaise safe undo actions.
9. Remote repository integration.
10. Beginner-friendly command explanations.
11. Protected branches aur permissions.
12. Optional security checks through integrations.

## 5. Pages / screens
Dashboard, Repositories, Repository Details, File Browser, Changes, Commit History, Branches, Merge Conflicts, Remotes, Pull Requests (connected provider par depend karega), Learning Playground, Settings, Users & Roles.

## 6. Main workflow
User repo clone ya create karta hai, files badalta hai, diff check karta hai, changes stage karke commit karta hai aur phir remote par push karta hai. Conflict ho to tool bataye ki kaunse parts ko resolve karna hai.

## 7. Technical planning
Actual Git operations ke liye existing Git implementation use karna zyada practical hai. UI aur Git operation layer ko alag rakhein. Large repositories, binary files aur submodules ke saath testing karein.

## 8. Security
Git hooks ya repository scripts untrusted code chala sakte hain. Credentials plain text mein save na karein. Reset/clean jaise destructive actions se pehle preview, warning aur recovery guidance dein.

## 9. Development phases
- Phase 1: Repository history, diff aur basic Git learning.
- Phase 2: Branches, commits aur conflict help.
- Phase 3: Remote hosting integration aur pull request links.
- Phase 4: Team policies, security integrations aur advanced workflows.

## 10. Success metrics
Git tasks complete karne ka time, conflict solve hone ka rate, accidental data loss, push/pull errors aur beginner learning completion.

## 11. Risks
Git aur GitHub ek cheez nahi hain. Git version control system hai; GitHub online hosting/collaboration service hai. Product ke naam, scope aur features mein ye difference clear rakhein.

## 12. Original product idea
Git history ko visual timeline mein dikhayein aur har action ke saath simple explanation dein: kya badlega, risk kya hai aur undo kaise kar sakte hain.
